## 02 / 当前焦点

最近的工作集中在媒体安全、本地资料库与自托管网络工具。项目状态与星标核对于 **2026-10-05**。

### Now Building

- **[Kocpy](https://github.com/sexyfeifan/Kocpy)** — macOS 素材安全备份与项目归档工作台；多目标复制、回读校验、异常恢复与专业报告。 `TypeScript · Electron` ★2
- **[Kanbox macOS](https://github.com/sexyfeifan/Kanbox_macOS)** — 本地优先的小红书资料库；正文与媒体保存、OCR、每日回顾、完整归档与 iCloud 资料管理。 `Tauri · Next.js` ★2
- **[Natter-GUI](https://github.com/sexyfeifan/Natter-GUI)** — 为 Linux 与 NAS 管理 Natter 端口映射；TCP / UDP 服务、网络体检、运行状态与日志。 `Python · Docker`

### Maintained Systems

- **[Coralbay-Rules](https://github.com/sexyfeifan/Coralbay-Rules)** — 自托管订阅转换、分流配置与规则镜像平台；支持 Mihomo、OpenClash、Stash 与 Docker 部署。 `Go · Docker` ★1
- **[Nodus](https://github.com/sexyfeifan/Nodus)** — frpc Web 管理面板；多节点、代理规则、连接状态、配置导入与旧版数据迁移。 `Go · React · TypeScript` ★1
- **[Pocket-OS](https://github.com/sexyfeifan/Pocket-OS)** — 内容创作排期系统；独立工序、甘特图、历史恢复与 Canbox / 飞书项目导入。 `JavaScript · Docker`
