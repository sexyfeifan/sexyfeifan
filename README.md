## 我在做什么

我喜欢从真实使用场景出发做产品：片场里不能出错的数据备份、团队看得懂的排期、不会被平台困住的个人资料库，以及安静待在菜单栏里、把重复操作自动完成的工具。

- 🎬 **影视与内容生产**：素材卸载、校验、归档、通告排期与制作流程
- 🗃️ **本地优先**：数据留在本机、iCloud 或自己的 NAS，隐私和可迁移性优先
- 🖥️ **桌面体验**：Swift / SwiftUI、Tauri 与 Electron，关注原生交互和稳定交付
- 🧰 **自托管**：用 Docker 和自动化把部署、更新、备份做得更简单

> 目前账号有 **36 个公开仓库**；其中 **21 个是自己维护的项目仓库**（不含本主页与 forks）。2026 年已有 **1,000+ 次公开贡献**。
